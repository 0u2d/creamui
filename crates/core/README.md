# creamui-core

The foundation of CreamUI's native widget system.

This crate defines `Widget`, `Painter`, scene construction, hit testing, and the layout types re-exported from Taffy. Most applications should use it together with `creamui-widgets`, `creamui-render`, and `creamui-theme` rather than implementing the low-level traits directly.

See the [CreamUI getting-started guide](https://github.com/sammwyy/creamui/blob/main/docs/getting-started.md) for an application-level introduction.
